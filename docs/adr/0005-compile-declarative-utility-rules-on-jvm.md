# Compile declarative utility rules on the JVM

Compile CSS-oriented rules for a [Utility CSS library](../glossary/README.md#utility-css-library) entirely on the JVM, while continuing to accept finite CSS. Declarative rules let agents author and inspect tokens, families and variants without publishing executable callbacks, encoding CSS in a second schema, scanning applications or adding a generator process. Keep the language behind a narrow internal interface; Java declarations and shared CSS naming remain outside its grammar.
