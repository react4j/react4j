title: IntelliJ IDEA IDE Setup
---

Import the application's build configuration and use the same Java and processor settings as [Project Setup](project_setup.md). Library/generated bytecode targets Java 17; the JVM running annotation processing must be Java 21 or later. Bazel remains the authoritative verification path for this repository.

## Configure the Annotation Processors

Enable annotation processing for the application module. If processor discovery is configured manually, use the assembled `react4j-processor` jar and compatible Arez/Sting processor jars when needed. Keep the processor path separate from the application runtime classpath. Add the formatter JVM exports or disable generated source formatting as described in Project Setup.

![Annotation processor configuration example](/img/IntelliJ-AnnotationProcessor.png)

## Enable Auto Build

Automatic builds can refresh generated APIs while editing. Ensure the IDE's compiler settings match the command-line build, including JSpecify dependencies and `-XDaddTypeAnnotationsToSymbol=true`. UI labels vary between IDE versions; the screenshot illustrates the compiler settings rather than a required version-specific registry workaround.

![Automatic build configuration example](/img/IntelliJ-EnableAutoBuild.png)

## Add Generated Source to Path

Mark the build's annotation processor output as generated sources so builders and enhanced views are available to navigation and completion. Let the build regenerate these files rather than editing them. Keep the processor's invalid diagnostic fixtures outside ordinary IDE source roots.
