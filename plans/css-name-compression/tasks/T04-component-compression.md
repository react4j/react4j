# T04 — Component compression through a real link

- Status: `pending`
- Blocked by: T03
- Spec coverage: R5–R7 class/control/evidence portions; AC4–AC5 corresponding portions.

## Delivers

Component roots and modifiers shorten consistently in actual optimized JS and CSS using one versioned deterministic table, with independently selectable compression and prefix controls and a public reverse artifact.

## Acceptance criteria

- [ ] Use the owned/CSS-only inventory and stable policy established in T02; extend getter metadata with canonical symbol composition and hard-cut obsolete schema. Start allocation with component class symbols, retaining other kinds until T05.
- [ ] Normal resolved `defs` configure both catalogue and compiler, including select; defaults ADVANCED on, BUNDLE/development off, explicit false preserves optimization/pruning, optional string prefix applies only to compressed names.
- [ ] Validate boolean/string types, invalid prefixes and conflicting settings; consume only the exact recognized CSS defines without muting unrelated unknown-define warnings.
- [ ] Root and modifier tokens map independently then getters rebuild values. Preserve imports, aliases and inlining; stable class tokens remain readable.
- [ ] Preserve canonical binding composition when different getters share readable text; do not merge their compression policies, kinds or activation dependencies.
- [ ] Allocate deterministically with reserved names/grammar protection; collision checking uses immutable table. Evidence binds policy/table/JS/catalogue/mode; versioned reverse JSON includes every candidate/accessor/origin and is excluded from browser assets.
- [ ] Parser-aware replacements preserve existing CSS anchor maps and shifting positions; never globally replace matching text.

## Validation

- Unit tests for metadata round trips/invalid data, allocation/reservations/determinism, switches/prefix types and tampered evidence.
- Actual development, optimized, optimized-uncompressed and prefixed SaveButton builds; browser root/modifier application, independent variants and reverse artifact inspection.
- Class replacement map queries before/inside/after emitted changes; keep later kinds/maps under explicit T05/T06 ownership.
